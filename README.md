# Codemate

![Codemate](https://codemate-umber.vercel.app/home.png)

A place to find someone to code with.

Codemate is a developer matching app where you can meet other developers, connect with someone new, and work together through video calls. The idea is pretty simple: coding doesn't always have to be a solo thing.

## What I'm building

- Find and match with other developers
- Create a profile and manage your account
- Video calls with matched developers
- Authentication with protected routes
- A dashboard to manage your experience

I'm still working on it, so some parts may change as the project grows.

## Built with

- Next.js
- React
- Tailwind CSS
- Node.js and Express
- MongoDB
- Zustand
- WebRTC for video calls

Running locally

Clone the repository:

git clone https://github.com/PiyuSX/codemate.git
cd codemate

Frontend

Go to the frontend folder and install the dependencies:

cd frontend
npm install

Set up your .env.local file using the example env file, then run:

npm run dev

Backend

Open another terminal and go to the backend folder:

cd backend
npm install

Set up your .env file using the example env file, then run:

npm run dev

Both the frontend and backend need to be running for the app to work properly.

Status

Codemate is still a work in progress. I'm building it step by step and adding things as I go.
