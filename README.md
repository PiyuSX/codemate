# Codemate

![Codemate](https://codemate-umber.vercel.app/home.png)

A place to find someone to code with.

Codemate is a developer matching app where you can meet other developers, connect with someone new, and work together through video calls. The idea is pretty simple: coding doesn't always have to be a solo thing.

## What I'm building

- Find and match with other developers
- Create a profile and manage your account
- Video calls with matched developers
- Authentication with protected routes
- A dashboard to manage your experience

I'm still working on it, so some parts may change as the project grows.

##How it works
-Users can create an account setup their dev profile and find other devs to connect with, we call them mates.Once matched they can start a random video call and collab while discussing their common language and start working on a challange or project on the platform.

#Future plans 
-Improve the dev matching experience 
-Add more profile customization options
-Add more language support

## Built with

- Next.js
- React
- Tailwind CSS
- Node.js and Express
- MongoDB
- Zustand
- WebRTC for video calls

## Running locally

Clone the repository:

```bash
git clone https://github.com/PiyuSX/codemate.git
cd codemate
```
Open Terminal in CodeEditor then
For Frontend
```bash
cd frontend
npm run dev
```

Open Another Terminal in CodeEditor then

```bash
cd backend
npm run dev
```

You'll also need to configure the environment variables for your local setup.
I have provided example env for it
